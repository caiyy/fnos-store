安装

1. 安装商店

从 Cocode Store Release 下载对应架构的 cocode-store_*.fpk，在飞牛应用中心上传。

2. 安装 Agent2API

从 Agent2API_Release 下载 agent2api_*.fpk，或直接在 Cocode Store 中安装。

3. 首次配置

打开 Agent2API，注册管理员并创建网关 Key，默认端口为 3065。
